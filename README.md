# greta-oto-secure-ops-assistant
SecureOps Assistant — a grounded RAG system that helps security analysts navigate industrial cybersecurity guidance (NIST SP 800-82 Rev. 3, NIST CSF 2.0, CISA ICS advisories). Every answer is cited to its source, and the assistant refuses to guess when the corpus can't support an answer. Built for the WMG Applied AI Hackathon 2026.
